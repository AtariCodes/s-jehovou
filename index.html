Synchronizace a záloha

Zápisky se ukládají do tvého soukromého repozitáře na GitHubu. Na každém zařízení stačí jednou vyplnit repozitář a token.

Jak získat token
  1. Otevři github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. U „Repository access“ zvol „Only select repositories“ a vyber repozitář s daty.
  3. V „Permissions → Repository permissions“ nastav „Contents“ na „Read and write“.
  4. Token vygeneruj, zkopíruj a vlož sem. Ukládá se jen v tomto zařízení.
